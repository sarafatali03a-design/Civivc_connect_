CivicConnect – Public Facility Feedback System

About the Project

CivicConnect is a web-based platform that allows citizens to submit feedback and report issues related to public facilities such as hospitals, bus stands, parks, schools, water supply, and public toilets.

The website aims to make feedback submission and tracking simple, organised, and accessible.

Features

- View different public facilities.
- Search and filter facilities.
- Submit complaints and suggestions.
- Generate a feedback reference number.
- Track feedback status.
- View feedback statistics on the dashboard.

Technologies Used

- HTML: Website structure and content.
- CSS: Design, layout, and styling.
- JavaScript: Functionality and interactivity.

How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open "index.html" using Live Server or a web browser.

Note

This is an academic front-end prototype. Feedback data is stored locally in the browser and is not connected to any official government system.

Conclusion

CivicConnect demonstrates how HTML, CSS, and JavaScript can be used to create a simple platform for collecting and tracking public facility feedback.

Developed as a group academic project.
